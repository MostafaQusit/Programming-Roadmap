# قائمة بأهم أوامر Git (خاصة باستخدام GitHub)

## 1. إعداد Git لأول مرة
- إعداد اسم المستخدم الخاص بك.
```bash
git config --global user.name "اسمك"
```

- تحديد بريدك الإلكتروني المستخدم في الـ commits.
```bash
git config --global user.email "بريدك الإلكتروني"
```

---

## 2. إنشاء مستودع (Repository)
- إنشاء مستودع Git جديد في المجلد الحالي.
```bash
git init
```

- نسخ مستودع موجود من GitHub إلى جهازك.
```bash
git clone [رابط المستودع]
```

---

## 3. التعامل مع الملفات
- إضافة ملف معين إلى منطقة الإعداد (staging area).
```bash
git add [اسم الملف]
```

- إضافة كل الملفات المعدلة أو الجديدة إلى منطقة الإعداد.
```bash
git add .
```

- حذف ملف من المستودع.
```bash
git rm [اسم الملف]
```

- إعادة تسمية ملف.
```bash
git mv [اسم الملف القديم] [اسم الملف الجديد]
```

---

## 4. إدارة التغييرات
- حفظ التغييرات في المستودع مع رسالة وصفية.
```bash
git commit -m "رسالة التغيير"
```

- عرض حالة الملفات (معدلة، مضافة، غير متتبعة).
```bash
git status
```

- عرض التغييرات بين الملفات غير الملتزمة.
```bash
git diff
```

- عرض سجل التغييرات (commits).
```bash
git log
```

- عرض سجل التغييرات بطريقة مختصرة.
```bash
git log --oneline
```

---

## 5. العمل مع الفروع (Branches)
- عرض قائمة الفروع الحالية.
```bash
git branch
```

- إنشاء فرع جديد.
```bash
git branch [اسم الفرع]
```

- التنقل بين الفروع.
```bash
git checkout [اسم الفرع]
```

- إنشاء فرع جديد والتنقل إليه مباشرة.
```bash
git checkout -b [اسم الفرع]
```

- دمج فرع محدد مع الفرع الحالي.
```bash
git merge [اسم الفرع]
```

- حذف فرع معين.
```bash
git branch -d [اسم الفرع]
```

---

## 6. العمل مع GitHub
- ربط المستودع المحلي بمستودع GitHub.
```bash
git remote add origin [رابط المستودع]
```

- إرسال التغييرات لأول مرة إلى فرع معين في GitHub.
```bash
git push -u origin [اسم الفرع]
```

- إرسال التغييرات الأخيرة إلى GitHub.
```bash
git push
```

- تحديث المستودع المحلي من GitHub.
```bash
git pull
```

- جلب التحديثات من GitHub دون دمجها تلقائيًا.
```bash
git fetch
```

---

## 7. إصلاح الأخطاء والتراجع
- إزالة ملف من منطقة الإعداد (staging area).
```bash
git reset [اسم الملف]
```

- التراجع عن آخر commit مع الحفاظ على التغييرات.
```bash
git reset --soft HEAD~1
```

- التراجع عن آخر commit وحذف التغييرات تمامًا.
```bash
git reset --hard HEAD~1
```

- التراجع عن commit معين بإنشاء commit جديد.
```bash
git revert [معرف commit]
```

---

## 8. عرض الحالة
- عرض التفاصيل الكاملة للـ commit الأخير.
```bash
git show
```

- عرض من قام بتعديل كل سطر في ملف معين.
```bash
git blame [اسم الملف]
```

- وضع علامة على نقطة معينة في التاريخ (إصدار).
```bash
git tag [اسم الإصدار]
```

---

## 9. التنظيف والصيانة
- حذف الملفات غير المتتبعة.
```bash
git clean -f
```

- تحسين المستودع عن طريق تنظيف البيانات القديمة.
```bash
git gc
```
